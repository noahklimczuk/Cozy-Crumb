# Workflow Rules

## Git Workflow
- **Branching**: For every new prompt/task, check out and pull latest `main`, then create a fresh descriptive branch off `main` (e.g., `feat/...`, `fix/...`, `chore/...`).
- **Pull Requests**: Every new prompt/task gets a fresh Pull Request for its branch.

## Autonomy
- **File Changes & Execution**: Do not ask for permission to modify, create, or delete files or execute commands. Proceed autonomously to implement and verify requested changes directly.
